# Case Study Writer

## Trigger
- Customer success story request
- Usage data and interview notes provided
- Target length specified (800-1500 words)

## Steps
1. Extract customer details and challenge
2. Structure: Challenge → Solution → Implementation → Results
3. Quantify results with metrics (ROI, time saved, efficiency gains)
4. Add customer quotes from interviews
5. Include visual data points (charts, stats)
6. Send to technical-reviewer
7. Store in ContentRepository

## Example
User: Write case study for Acme Corp automation implementation
Agent: Drafted case study: 65% time savings, 40-hour/week automation, 8-week implementation. 3 customer quotes included. Results section highlights $200K annual savings.

**Note**: Consult knowledge-base.md for case study templates.
