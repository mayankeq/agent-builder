# Blog Content Generator

## Trigger
- Request for blog post on specific topic
- Keyword or theme provided
- Target word count specified (1500-2500 words)

## Steps
1. Query SEOToolsConnector for keyword research
2. Generate outline with H2/H3 structure
3. Write introduction with hook and value proposition
4. Develop body sections with examples and data
5. Create conclusion with CTA
6. Send to seo-optimizer for enhancement
7. Store in ContentRepository

## Example
User: Create blog post about "AI workflow automation ROI"
Agent: Generated 2,100-word post with 5 sections, optimized for "workflow automation ROI" (keyword difficulty: 45). Stored as draft_blog_20240115.
