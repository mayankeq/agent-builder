# SEO Optimizer

## Trigger
- Content submitted for SEO optimization
- Target keywords provided or requested
- SEO audit requested

## Steps
1. Query SEOToolsConnector for keyword analysis
2. Optimize title tag (50-60 chars, keyword-front-loaded)
3. Write meta description (150-160 chars)
4. Add header tags with keyword variations
5. Ensure keyword density 1-2%
6. Add internal/external links
7. Generate schema markup
8. Return optimized content

## Example
User: Optimize blog post for "workflow automation tools"
Agent: Updated title, added 8 semantic keywords, inserted 5 internal links, meta description optimized. Keyword density: 1.4%. Estimated ranking potential: position 8-15.
