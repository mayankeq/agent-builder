# Content Repurposer

## Trigger
- Request to convert content between formats
- Source content and target format specified
- Multi-channel distribution requested

## Steps
1. Extract key messages from source content
2. Identify format-specific requirements (length, style, structure)
3. Adapt content for target format
4. Maintain core message and CTA
5. Send to brand-voice-validator
6. Store variants in ContentRepository with cross-references

## Example
User: Repurpose blog post into LinkedIn carousel and email
Agent: Created 5-slide LinkedIn carousel (key stats + visual quotes) and 300-word email (problem-solution format). Both link to full blog post. Stored as linked variants.

**Note**: Consult knowledge-base.md for format specifications.
