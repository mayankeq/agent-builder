# Technical Whitepaper Author

## Trigger
- Request for technical whitepaper on AI/workflow topic
- Target audience level specified (technical/executive)
- Length specified (3000-5000 words)

## Steps
1. Research topic via KnowledgeBaseManager
2. Create executive summary
3. Develop technical sections with architecture diagrams
4. Include data, research citations, and best practices
5. Add implementation guidelines
6. Send to technical-reviewer for accuracy
7. Format for lead capture and store

## Example
User: Create whitepaper on "Enterprise Workflow Orchestration Architecture"
Agent: Generated 4,200-word whitepaper with 6 sections, 3 architecture diagrams, 12 citations. Covers microservices, event-driven design, scalability patterns.

**Note**: Consult knowledge-base.md for technical accuracy.
