# Brand Voice Validator

## Trigger
- Content submitted for brand validation
- Style guide compliance check requested
- Tone/voice verification needed

## Steps
1. Query KnowledgeBaseManager for brand guidelines
2. Check tone consistency (professional/conversational ratio)
3. Verify terminology and product names
4. Validate messaging framework alignment
5. Flag deviations with specific suggestions
6. Approve or return with corrections

## Example
User: Validate blog post for brand voice
Agent: 2 issues found: (1) "utilize" → change to "use" for conversational tone, (2) Product name capitalization inconsistent in para 3. Otherwise compliant with brand guidelines.

**Note**: Consult knowledge-base.md for complete style guide.
