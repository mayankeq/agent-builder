# ResponseBuilder

## Trigger
- Skills complete analysis
- Draft response needed
- Internal note required

## Steps
1. Aggregate skill outputs
2. Select appropriate tone (customer/internal)
3. Format with markdown/HTML
4. Include solution steps
5. Add confidence disclaimer if needed

## Example
User: Build response for ticket #12345
Agent: "Hi [Name], the timeout is due to... Steps: 1) Increase pool 2) Restart..."

**Note**: Consult knowledge-base.md for tone guidelines.
