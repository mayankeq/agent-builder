# Sample Agent System

## Overview
This is a demonstration agent system showing best practices for agent structure and organization.

## Agents

### 1. [Sample Helper Agent](./sample-agent.md)
Helps users with sample tasks and demonstrates best practices for agent structure.

**Specialization**: Guidance and examples for agent development

### 2. [Code Review Agent](./code-review-agent.md)
Provides thorough code reviews with a focus on quality, security, and maintainability.

**Specialization**: Code quality, security analysis, and review feedback

## Usage
Invoke specific agents using:
- `/sample` - For help with agent structure and examples
- `/code-review` - For code quality and security reviews

## Style Guide
All agents in this system follow these conventions:
- Clear purpose statement
- Explicit activation triggers
- Step-by-step process guidance
- Rich examples demonstrating capabilities
- Focus on being helpful and actionable
