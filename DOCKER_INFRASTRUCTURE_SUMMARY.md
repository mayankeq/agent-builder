## Architecture

### Service Configuration

```yaml
Services in docker-compose.yml:
├── postgres (PostgreSQL 15)
│   ├── Port: 5432
│   ├── Health check: pg_isready
│   ├── Auto-migrates on startup
│   └── Persistent volume: postgres-data
│
├── redis (Redis 7)
│   ├── Port: 6379
│   ├── Health check: redis-cli ping
│   └── Persistent volume: redis-data
│
├── backend (Node.js + Express)
│   ├── Port: 3000
│   ├── Target: development (hot reload)
│   ├── Health check: GET /health
│   ├── Depends on: postgres, redis
│   └── Volume mounts: src/, config/, templates/
│
├── frontend (React + Vite)
│   ├── Port: 5173
│   ├── Target: development (hot reload)
│   ├── Health check: GET /
│   ├── Depends on: backend
│   └── Volume mounts: web/src/
│
└── migrator (One-time runner)
    ├── Runs: node scripts/migrate.js up
    ├── Depends on: postgres
    └── Restart: no
```

### Multi-Stage Docker Builds

**Backend (Dockerfile.backend):**
```
deps → builder → development (used by compose) → production
```

**Frontend (web/Dockerfile):**
```
deps → development (used by compose) → builder → production (nginx)
```

### Development Features

1. **Hot Reload**
   - Backend: Source code mounted, auto-rebuild on change
   - Frontend: Vite dev server, instant HMR

2. **Isolated Node Modules**
   - Named volumes prevent conflicts with host
   - Backend: `backend-node-modules` volume
   - Frontend: `frontend-node-modules` volume

3. **Persistent Data**
   - Database: `postgres-data` volume
   - Redis: `redis-data` volume
   - Artifacts: `./artifacts` bind mount
   - Logs: `./logs` bind mount

4. **Automatic Migrations**
   - Migrator service runs on startup
   - Waits for postgres to be healthy
   - Exits after successful migration

## Usage

### Quick Start

```bash
# One command to rule them all
./setup.sh
```

This will:
1. ✅ Check Docker is installed
2. ✅ Create .env file from template
3. ✅ Prompt for Anthropic API key
4. ✅ Generate JWT and encryption secrets
5. ✅ Start all 5 services in Docker
6. ✅ Wait for health checks
7. ✅ Open browser to http://localhost:5173

**Total time: ~3 minutes**

### Verification (Optional)

Before running setup, verify everything is ready:

```bash
./verify-docker-setup.sh
```

This checks:
- Prerequisites (Docker, Docker Compose, Node.js)
- All required files exist
- File syntax is valid
- Configuration is consistent
- Ports are available
- Docker daemon is running
- Sufficient disk space and memory

### Manual Commands

```bash
# Start all services
docker-compose up -d

# View logs
docker-compose logs -f

# Stop services (keeps data)
docker-compose down

# Stop and remove all data
docker-compose down -v

# Restart a service
docker-compose restart backend

# Rebuild a service
docker-compose up -d --build backend
```

## Production Deployment

The same Dockerfiles support production builds:

```bash

docker build -f Dockerfile.backend --target production -t agent-builder-backend:prod .

# Build production frontend (with nginx)
docker build -f web/Dockerfile --target production -t agent-builder-frontend:prod ./web
```

Production features:
- Non-root users for security
- Optimized layer caching
- Minimal image sizes
- Built-in health checks
- Nginx for frontend with:
  - Gzip compression
  - Cache headers
  - Security headers
  - API proxy
  - WebSocket proxy

## Troubleshooting

### Common Issues

| Issue | Solution |
|-------|----------|
| "Port already in use" | Stop conflicting service or change port in docker-compose.yml |
| "Docker daemon not running" | Start Docker Desktop |
| "Backend failed to start" | Check logs: `docker-compose logs backend` |
| "Database connection error" | Wait 30s for postgres to initialize |
| "Hot reload not working" | Restart service: `docker-compose restart <service>` |

### Getting Help
